Xbox- und Microsoft-Store-Spiele haben endlich ihr Symbol: Bei diesen Titeln steckt das Icon nicht in der Programmdatei, sondern liegt als Bild im Spielordner – Lumora fand dort bisher nichts und zeigte die Kachel leer. Jetzt wird das Paketlogo des Spiels verwendet. Bereits vorhandene Einträge holen ihr Symbol beim nächsten Anwählen automatisch nach; ein selbst gesetztes Bild bleibt dabei erhalten.
===EN===
Xbox and Microsoft Store games finally show their icon: for those titles the icon is not stored in the executable but sits as an image in the game folder – Lumora found nothing there and left the tile blank. It now uses the game's package logo. Entries you already have fetch their icon automatically the next time you select them; a custom image you set yourself is kept.

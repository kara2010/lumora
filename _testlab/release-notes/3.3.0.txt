Ruckler-Berichte lassen sich jetzt teilen – mit einem Link statt mit abgetippten Zahlen. Aus jedem Bericht wird auf Wunsch eine aufgeräumte Seite, die den Befund, die Frametime-Kurve und die Verdächtigen genauso zeigt wie die App: ideal für ein Forum, einen Support-Thread oder die Frage „ist das bei dir auch so?". Teilen ist immer eine bewusste Einzelentscheidung, und vorher steht wörtlich da, was gesendet wird. Dateipfade werden grundsätzlich entfernt; Prozessnamen und der Spielname lassen sich zusätzlich weglassen, ohne dass die Aussage verlorengeht. Eigene Notizen bleiben immer auf dem Rechner. Es wird kein Konto angelegt, nichts wird verknüpft, und jeder geteilte Bericht lässt sich jederzeit wieder zurückziehen – der Link ist dann tot.

Außerdem behoben: Wer einen Gamepad-Hotkey vergeben hatte, in dem die A-Taste vorkommt (etwa „A + LB" für das Overlay), konnte mit A keine Spiele mehr starten – die Taste war stillschweigend für alles andere gesperrt. Jetzt zählt sie wieder ganz normal, solange sie allein gedrückt wird; die Kombination löst weiterhin nur den Hotkey aus. Das Gleiche galt für B, X, Y und Start. Beim Aufnehmen einer Kombination weist Lumora jetzt außerdem darauf hin, wenn eine Steuerkreuz-Taste darin steckt und dadurch für die Navigation ausfällt.
===EN===
Stutter reports can now be shared – with a link instead of retyped numbers. Any report can be turned into a clean page that shows the verdict, the frame time curve and the suspects exactly as the app does: ideal for a forum, a support thread, or the question "does this happen to you too?". Sharing is always a deliberate, single decision, and you see the exact text that will be sent beforehand. File paths are always removed; process names and the game name can optionally be left out without losing the conclusion. Your own notes never leave your PC. No account is created, nothing is linked, and any shared report can be withdrawn at any time – the link then goes dead.

Also fixed: anyone who had assigned a gamepad hotkey containing the A button (for example "A + LB" for the overlay) could no longer launch games with A – the button was silently disabled for everything else. It now works normally again as long as it is pressed on its own; the combination still triggers only the hotkey. The same applied to B, X, Y and Start. When recording a combination, Lumora now also points out when it contains a D-pad button that will consequently be unavailable for navigation.

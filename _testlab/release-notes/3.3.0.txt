Diese Version behebt zwei Fehler, die beim Bedienen per Gamepad und beim Umstieg von der früheren Version auffielen. Hattest du einen Gamepad-Hotkey vergeben, in dem die A-Taste vorkommt (etwa „A + LB" fürs Overlay), ließen sich mit A keine Spiele mehr starten – die Taste war stillschweigend für alles andere gesperrt. Jetzt startet A wieder ganz normal Spiele, während die Kombination weiterhin nur den Hotkey auslöst; das Gleiche galt für B, X, Y und Start. Außerdem zeigte die Taskleiste bei Umsteigern von der alten Version fälschlich „Electron" ohne Symbol, weil eine tote Verknüpfung aus der Vorgängerversion die App-Identität überlagerte – der Installer räumt diese jetzt auf. Dazu lädt Lumora Bibliothek und Einstellungen beim Start robuster, sodass ein kurzer Aussetzer direkt nach einem Absturz nicht mehr fälschlich die Spielesuche öffnet.
===EN===
This release fixes two issues that showed up when using a gamepad and when upgrading from the earlier version. If you had assigned a gamepad hotkey containing the A button (for example "A + LB" for the overlay), you could no longer launch games with A – the button was silently disabled for everything else. A now launches games normally again, while the combination still triggers only the hotkey; the same applied to B, X, Y and Start. In addition, the taskbar wrongly showed "Electron" without an icon for users upgrading from the old version, because a dead shortcut from the previous release overrode the app identity – the installer now cleans this up. On top of that, Lumora loads your library and settings more robustly at startup, so a brief hiccup right after a crash no longer wrongly opens the game scan.

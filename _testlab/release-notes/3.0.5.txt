Doppelstart-Schutz: Solange ein Spiel läuft oder gerade startet, wird kein zweites gestartet (auch keine zweite Instanz desselben Spiels).

Intel-Grafik: Live-Bitraten-Wechsel greifen jetzt auch auf älteren Intel-Generationen (z. B. HD 630), auf denen der Treiber die nahtlose Umstellung ablehnt – der Encoder wird dort automatisch kurz neu initialisiert.

Xbox controller: Reconnecting the controller (Xbox Wireless Dongle) while Lumora is running is now stable. The UI's gamepad polling (Chromium's gamepad monitor probing empty controller slots) disrupted the pairing handshake – controller input is now handled fully natively.

OSD: The overlay no longer blocks clicks on desktop icons – even while hidden. An internal WebView2 window sat invisibly over the panel area and swallowed clicks; it is now made click-through.

Game-end detection: Lumora now detects a game closing within 1–3 seconds (previously up to 12) – HDR switches back accordingly faster. Detection reacts directly to process exit instead of a polling grid.

Double-launch guard: While a game is running or starting, no second game can be launched (including a second instance of the same game).

Launch button: Shows the current session time live while a game is running ("Game running · 12 min").

Update check: "Check for updates" works again (the default feed address pointed to a wrong path).

Intel graphics: Live bitrate changes now also apply on older Intel generations (e.g. HD 630) where the driver rejects seamless reconfiguration – the encoder is briefly re-initialized automatically there.
